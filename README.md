# ArQmA Network Bot (ZMQ-RPC first, robust)\n\n- Primary data via ZMQ-RPC tcp://<host>:19995 for /nodes and /daemon_info.\n- If get_info top hash is zero/missing, bot calls get_last_block_header and uses that hash.\n- If version is missing, bot calls get_version and normalizes it (e.g., major.minor).\n- Correct hashrate = difficulty / target (fallback target = 120s).\n- HTTP fallback only if ZMQ-RPC yields no meaningful data.\n- /restrict (24h) logged in data/restricted.txt and enforced on Telegram & Discord.\n- /zmqdiag <NodeName> for admin diagnostics (pattern used + raw JSON).\n\nSetup:\n1) node generate-structure.js\n2) npm install\n3) fill .env\n4) run daemons with --zmq-rpc-bind-ip 0.0.0.0 --zmq-rpc-bind-port 19995\n5) open TCP 19995\n6) edit config/nodeList.js with public hosts\n7) npm start\n
